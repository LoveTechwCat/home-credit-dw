# reports/latex/diagrams

- Chương 2: `hc_description.mmd` (fig:hc_description), `star_schema.mmd` (fig:star_schema), `etl_pipeline.mmd` (fig:etl_pipeline), `data_lineage.mmd` (fig:data_lineage)
